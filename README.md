# 아트공조 데모

빌드 없이 실행하는 HTML/CSS/JavaScript 사이트입니다. `dist`가 배포 디렉토리입니다.

- 업체명, 예시 연락처와 주소, 가상 아파트 데이터: `dist/config.js`
- 레이아웃과 한글 Pretendard 설정: `dist/style.css`
- 견적 모듈: `dist/quote.js`, `dist/quote.css`
- 홈, 검색, 상담 체험 및 콘텐츠: `dist/app.js`, `dist/index.html`

모든 견적과 사례는 데모입니다. 상담 폼은 서버로 전송하지 않으며 개인정보를 영구 저장하지 않습니다. 폰트는 사용자 지정 Pretendard CDN을 사용합니다.

로컬 확인: `node preview.mjs` 실행 후 터미널에 표시되는 주소를 엽니다.
